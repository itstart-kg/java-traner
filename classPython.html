01Что такое класс и объект

Класс — шаблон, который описывает, какие данные будут у объектов и что они умеют делать.

Объект (экземпляр) — конкретная вещь, созданная по шаблону, со своими значениями.

Класс = чертёж

«У дома есть адрес, этажи, цвет». Жить в чертеже нельзя.

Объект = дом

ул. Ленина 5, 9 этажей, белый. По одному чертежу — сколько угодно домов.
В Python всё — объектЧисла, строки, списки, функции и даже сами классы — объекты. type(5) вернёт <class 'int'>: число 5 — экземпляр класса int. Когда вы пишете свой класс, вы создаёте новый тип данных наравне со встроенными.

02Из чего состоит класс

  • Атрибуты — данные объекта (аналог полей в Java).
  • __init__ — инициализатор, выполняется при создании объекта и заполняет атрибуты.
  • Методы — функции внутри класса. Первый параметр — self.
student.py
class Student:
    # ===== Инициализатор =====
    def __init__(self, name, age):
        # Атрибуты объекта создаются прямо здесь
        self.name = name
        self.age = age
        self.gpa = 0.0

    # ===== Методы (поведение) =====
    def introduce(self):
        print(f"Привет, я {self.name}, мне {self.age}")

    def study(self, hours):
        self.gpa += hours * 0.01
        print(f"{self.name} учился {hours} ч.")
Соглашения (PEP 8)Имена классов — PascalCase (BankAccount), методов и атрибутов — snake_case (get_balance). Отступ — 4 пробела. Пустой класс пишется как class Empty: pass.
Отличие от JavaАтрибуты не объявляются заранее с типами. Они появляются в момент присваивания self.name = .... Поэтому все атрибуты принято создавать в __init__ — так сразу видно, из чего состоит объект.

05self

self — ссылка на текущий объект, аналог this в Java. Отличие: в Python его нужно явно писать первым параметром каждого обычного метода.

06__init__ и «перегрузка»

В Python нет перегрузки методов и конструкторов по количеству параметров. Если написать два __init__, второй просто заменит первый. Вместо этого используют:

1. Значения по умолчанию

product.py
class Product:
    def __init__(self, title, price=0.0, quantity=1):
        self.title = title
        self.price = price
        self.quantity = quantity

a = Product("Ноутбук", 55000, 2)
b = Product("Мышь", 800)            # quantity = 1
c = Product("Подарок")              # price = 0.0, quantity = 1
d = Product("Кабель", quantity=5)   # именованный аргумент

2. Альтернативные конструкторы через @classmethod

from_string
class Product:
    def __init__(self, title, price=0.0, quantity=1):
        self.title = title
        self.price = price
        self.quantity = quantity

    @classmethod
    def from_string(cls, line):
        # "Ноутбук;55000;2" -> Product
        title, price, qty = line.split(";")
        return cls(title, float(price), int(qty))

p = Product.from_string("Ноутбук;55000;2")
print(p.title, p.price, p.quantity)
Ноутбук 55000.0 2

Так устроены стандартные классы: dict.fromkeys(...), datetime.fromtimestamp(...).

Ловушка: изменяемое значение по умолчаниюЗначение по умолчанию вычисляется один раз, при определении функции. Список по умолчанию окажется общим для всех объектов.

07Атрибуты класса и атрибуты объекта

Атрибут, объявленный прямо в теле класса (не через self), принадлежит классу и общий для всех объектов — аналог static-поля в Java.

user.py
class User:
    count = 0                   # атрибут класса
    MAX_LOGIN_LENGTH = 20       # «константа» (по соглашению — КАПСОМ)

    def __init__(self, login):
        User.count += 1         # меняем через имя класса
        self.id = User.count    # атрибут объекта
        self.login = login

u1 = User("aziz")
u2 = User("aigerim")
u3 = User("bektur")

print(User.count)   # 3
print(u3.id)        # 3
print(u1.count)     # 3 — чтение через объект тоже работает
3 3 3
Ловушка: запись через selfself.count += 1 НЕ изменит атрибут класса. Python прочитает User.count, прибавит 1 и создаст новый атрибут у объекта, который перекроет классовый. Менять атрибут класса нужно через имя класса или cls.
Как Python ищет атрибут
class A:
    x = 10

obj = A()
print(obj.x)      # 10 — нет у объекта, найден у класса
obj.x = 99        # создан атрибут у объекта
print(obj.x)      # 99 — объект
print(A.x)        # 10 — класс не изменился
print(obj.__dict__)   # {'x': 99} — атрибуты самого объекта
10 99 10 {'x': 99}

Порядок поиска: сначала атрибуты объекта (obj.__dict__), потом класса, потом родительских классов.

Констант нетВ Python нет аналога final. MAX_LOGIN_LENGTH технически можно изменить — капс лишь сигнал «не трогай». Для проверок типов есть typing.Final, но в рантайме он ничего не запрещает.

08Инкапсуляция: _ и __

В Python нет private/protected/public. Доступ ко всему открыт, а «закрытость» обозначается соглашениями об именах.

ИмяСмыслЧто делает Python

class Account:

        self._owner = "Азиз"      # внутренний
        self.__balance = balance   # «приватный»

На практикеЧаще всего используют одно подчёркивание _. Двойное нужно в основном, чтобы атрибут случайно не перекрылся в классе-наследнике. Принцип Python: «мы все взрослые люди» — язык не запрещает, а договаривается.

09@property: геттеры и сеттеры по-питоновски

Методы get_age()/set_age() как в Java в Python не пишут. Вместо них — @property: снаружи это выглядит как обычный атрибут, а внутри выполняется метод с проверкой.

student.py
class Student:
    def __init__(self, name, age):
        self.name = name      # уже идёт через сеттер ниже
        self.age = age

    @property
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        if not value or not value.strip():
            raise ValueError("Имя не может быть пустым")
        self._name = value

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if not 0 <= value <= 120:
            raise ValueError(f"Некорректный возраст: {value}")
        self._age = value

    @property
    def is_adult(self):       # вычисляемое свойство, только чтение
        return self._age >= 18


s = Student("Азиз", 19)
s.age = 20                 # вызывается сеттер
print(s.age)               # 20 — вызывается геттер
print(s.is_adult)          # True
s.age = -500               # ValueError: Некорректный возраст: -500
  • Синтаксис для пользователя класса простой: s.age = 20, без скобок.
  • Проверка срабатывает и в __init__, потому что там тоже self.age = ....
  • Свойство без .setter доступно только для чтения: s.is_adult = False → AttributeError.
Когда нужен propertyНе оборачивайте каждый атрибут. Начинайте с обычного self.age. Если позже понадобится проверка — замените на @property: код, который использует класс, менять не придётся.

10Обычные, static- и class-методы

Три вида методов
class Temperature:
    unit = "°C"

    def __init__(self, celsius):
        self.celsius = celsius

    # Обычный метод: работает с конкретным объектом через self
    def to_fahrenheit(self):
        return self.celsius * 9 / 5 + 32

    # Метод класса: получает класс через cls
    @classmethod
    def from_fahrenheit(cls, f):
        return cls((f - 32) * 5 / 9)

    # Статический метод: не получает ни self, ни cls
    @staticmethod
    def is_valid(celsius):
        return celsius >= -273.15


t = Temperature(25)
print(t.to_fahrenheit())                    # 77.0
print(Temperature.from_fahrenheit(212).celsius)  # 100.0
print(Temperature.is_valid(-300))           # False
77.0 100.0 False

11Магические методы (dunder)

Методы вида __имя__ Python вызывает сам в определённых ситуациях. С их помощью свой класс начинает работать с print, ==, +, len() и т. д.

МетодКогда вызывается
__init__Cls(...) — инициализация
__str__print(obj), str(obj), f-строки — текст для пользователя
__repr__Консоль, отладка, объект внутри списка — текст для разработчика
__eq__a == b
__lt__, __gt__…<, >; нужны для sorted()
__hash__hash(obj), ключи dict, элементы set

money.py
class Money:
    def __init__(self, amount, currency="KGS"):
        self.amount = amount
        self.currency = currency

    def __str__(self):
        return f"{self.amount} {self.currency}"

    def __repr__(self):
        return f"Money({self.amount!r}, {self.currency!r})"

    def __eq__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return self.amount == other.amount and self.currency == other.currency

    def __hash__(self):
        return hash((self.amount, self.currency))

    def __add__(self, other):
        if self.currency != other.currency:
            raise ValueError("Разные валюты")
        return Money(self.amount + other.amount, self.currency)

    def __lt__(self, other):
        return self.amount < other.amount


a = Money(500)
b = Money(300)
print(a)                    # __str__
print([a, b])               # __repr__ внутри списка
print(a + b)                # __add__
print(a == Money(500))      # __eq__
print(sorted([a, b]))       # __lt__
print(len({a, Money(500)})) # __hash__: одинаковые объекты в set — один элемент
500 KGS [Money(500, 'KGS'), Money(300, 'KGS')] 800 KGS True [Money(300, 'KGS'), Money(500, 'KGS')] 1
__eq__ и __hash__Если вы определили __eq__, но не __hash__, Python делает объект нехешируемым: его нельзя положить в set или использовать ключом dict (TypeError: unhashable type). Равные объекты обязаны иметь одинаковый хеш.
Без __str__ и __repr__print(obj) выведет что-то вроде <__main__.Money object at 0x7f...>. Если определён только __repr__, его использует и print.

12Наследование (кратко)

Наследование
class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(f"Я {self.name}")


class Student(Person):                 # Student наследует Person
    def __init__(self, name, university):
        super().__init__(name)         # вызов __init__ родителя
        self.university = university

    def introduce(self):               # переопределение
        super().introduce()
        print(f"Учусь в {self.university}")


p = Student("Азиз", "МУА")
p.introduce()
print(isinstance(p, Person))     # True
print(issubclass(Student, Person))  # True
Я Азиз Учусь в МУА True True
  • Родитель указывается в скобках: class Student(Person).
  • super() — доступ к методам родителя.
  • Если в наследнике есть свой __init__, родительский не вызывается автоматически — нужен super().__init__(...).
  • В отличие от Java, разрешено множественное наследование: class C(A, B). Порядок поиска методов задаёт MRO (C.__mro__).
  • Все классы неявно наследуются от object.

13dataclass: класс без шаблонного кода

Для классов, которые в основном хранят данные, есть декоратор @dataclass (Python 3.7+). Он сам генерирует __init__, __repr__ и __eq__.

dataclass
from dataclasses import dataclass, field

@dataclass
class Book:
    title: str
    author: str
    year: int = 0
    tags: list = field(default_factory=list)   # безопасный изменяемый default

    def is_classic(self):
        return 0 < self.year < 1950


b1 = Book("Джамиля", "Чингиз Айтматов", 1958)
b2 = Book("Джамиля", "Чингиз Айтматов", 1958)

print(b1)            # __repr__ сгенерирован
print(b1 == b2)      # __eq__ сгенерирован
print(b1.is_classic())
Book(title='Джамиля', author='Чингиз Айтматов', year=1958, tags=[]) True False

Полезные параметры: @dataclass(frozen=True) — объект нельзя изменить после создания (и он становится хешируемым); order=True — генерирует <, > для сортировки. Аннотации типов (title: str) Python в рантайме не проверяет.

14Полный пример: BankAccount

Всё вместе: атрибуты класса, «приватные» атрибуты, @property только для чтения, валидация, @classmethod, @staticmethod, __str__/__repr__.

bank_account.py
class BankAccount:
    MIN_DEPOSIT = 1.0            # «константа» класса
    _counter = 1000              # счётчик для номеров счетов

    def __init__(self, owner, pin, initial_balance=0.0):
        if initial_balance < 0:
            raise ValueError("Начальный баланс не может быть отрицательным")
        BankAccount._counter += 1
        self._number = f"KG-{BankAccount._counter}"
        self._owner = owner
        self.__pin = pin
        self._balance = initial_balance

    # ===== Альтернативный конструктор =====
    @classmethod
    def from_string(cls, line):
        # "Азиз;1234;5000"
        owner, pin, balance = line.split(";")
        return cls(owner, int(pin), float(balance))

    # ===== Свойства только для чтения =====
    @property
    def balance(self):
        return self._balance

    @property
    def number(self):
        return self._number

    @property
    def owner(self):
        return self._owner

    # ===== Поведение =====
    def check_pin(self, value):
        return self.__pin == value

    def deposit(self, amount):
        if amount < self.MIN_DEPOSIT:
            print(f"Минимальное пополнение: {self.MIN_DEPOSIT}")
            return
        self._balance += amount
        print(f"Пополнено: {amount}. Баланс: {self._balance}")

    def withdraw(self, amount):
        if amount <= 0:
            print("Сумма должна быть больше нуля")
            return False
        if amount > self._balance:
            print(f"Недостаточно средств. Баланс: {self._balance}")
            return False
        self._balance -= amount
        print(f"Снято: {amount}. Баланс: {self._balance}")
        return True

    def transfer_to(self, target, amount):
        if not isinstance(target, BankAccount) or target is self:
            print("Некорректный получатель")
            return False
        if self.withdraw(amount):
            target._balance += amount
            return True
        return False

    @staticmethod
    def is_valid_pin(pin):
        return isinstance(pin, int) and 1000 <= pin <= 9999

    # ===== Представление =====
    def __str__(self):
        return f"{self._number} | {self._owner} | {self._balance} сом"

    def __repr__(self):

15Частые ошибки новичков

  • Забыли self в параметрах метода → TypeError: ... takes 0 positional arguments but 1 was given.
  • Забыли self. при обращении к атрибуту: name = name вместо self.name = name.
  • Опечатка в __init__: __int__ или _init_ — инициализатор просто не вызовется.
  • Изменяемый default: def __init__(self, items=[]) — список общий для всех объектов.
  • Изменяемый атрибут класса: students = [] в теле класса — тоже общий для всех объектов. Списки создавайте в __init__.
  • self.count += 1 вместо ClassName.count += 1 — создаётся атрибут объекта, счётчик класса не меняется.
  • Наследник с __init__ без super().__init__() — атрибуты родителя не созданы.
  • __eq__ без __hash__ — объект нельзя положить в set/dict.
  • Сравнение с None через == вместо is None.
  • Java-стиль: get_x()/set_x() для каждого атрибута. В Python — обычный атрибут или @property.

Проверь себя

1. Зачем self в параметрах метода?Через него метод получает объект, у которого вызван. obj.m() превращается в Cls.m(obj), и obj попадает в self.
2. Что выведет код: a = Student("A", 1); b = a; b.age = 5; print(a.age)5. a и b — два имени одного объекта.
3. Можно ли написать два __init__ с разным числом параметров?Нет. Второе определение заменит первое. Используют значения по умолчанию или @classmethod.
4. Чем атрибут класса отличается от атрибута объекта?Атрибут класса один на всех (объявлен в теле класса). Атрибут объекта у каждого свой (создаётся через self.x = ...).
5. Что делает __balance (два подчёркивания)?Python переименовывает его в _ИмяКласса__balance. Снаружи по имени __balance не достать, но полной защиты нет.
6. Почему объект с __eq__ вдруг нельзя положить в set?Определение __eq__ без __hash__ делает __hash__ = None, и объект становится нехешируемым. Нужно определить __hash__ тоже.
7. Что не так: def __init__(self, items=[]):Список по умолчанию создаётся один раз и будет общим для всех объектов. Правильно: items=None, а в теле — self.items = items if items is not None else [].
